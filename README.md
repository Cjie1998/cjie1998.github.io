# 干支合战（月令合局）

《干支合战》是基于 `game.md` v3.5 实现的 1v1 网页卡牌游戏；当前模式名为 **月令合局**：你 vs 内置 AI。线上地址：**https://yinwei.xyz**。规则/策划与实现已经拆成两份文档：`game.md` 只写规则，`技术实施计划.md` 只写技术。
纯前端、零依赖、无需构建，规则引擎与 UI 分离。

![开局](screenshots/01-select.png)

## 快速开始

```bash
cd /home/cjie/temp/09_game
node server.mjs
```

浏览器打开 **[http://127.0.0.1:5180](http://127.0.0.1:5180)**，先进入「月令合局」大厅，点「进入月令合局」后才开始牌局。

也可以用 `npm start` 或 `./start.sh`。任意静态服务器（如
`python3 -m http.server 5180`）同样可以。

> 必须通过 HTTP 访问：项目使用 ES Modules，直接双击 `index.html`
> 会被浏览器的 `file://` 跨域策略拦截。

## 怎么玩

0. 打开页面先看到「月令合局」大厅；大厅不展示通用规则。首次点击「进入月令合局」后先打开本模式教程，可跳过；教程关闭后进入定月转盘：你先拖动月盘上弦、松手旋转，电脑再拨一次；两个结果随机取一，并随机顺逆，随后入局。
0.1 教程在转盘之前，共 6 步：五行生克制化 → 天干地支五行 → 月令与旺相休囚死（可选月令/干支实时试算）→ 会局/合局（卡牌图示）→ 摸牌与弃1摸1 → 积分与胜负。可随时跳过；牌局中右上角「教程」可重新打开。
1. 一局固定 **12 回合**。开局随机起点月令，并随机 **顺行或逆行**，之后整局方向固定，12 回合正好走完十二个月。
2. 每回合在 60 秒内把 1–3 张手牌拖到中间「出牌池」：单张自动转化，多张能合会自动合成五行牌；点「出牌」确认，点「清空」把牌退回手牌。点击手牌只用于「弃1摸1」：选 1 张弃掉，再从 4 天干 + 4 地支的暗池里盲选 1 张，选中前看不到牌面。也可以点「空过」保留手牌、推进月令；倒计时归零则本回合超时。
3. 对手本轮动作出牌阶段已暗定：若对手出牌，对战槽先显示一张牌背；你出牌后，对手牌面才揭示，随后只公开产出的五行牌（五行、分数、组合类型）。
4. 计分：普通单牌 = 5 + 2×自身五行旺相（1–9 分）；月令支单牌固定 10 分（5 + 月令 5，不再叠旺相）。组合 = 5×张数 + 组合加成 + 产出五行旺相（只加一次），不再累加每张牌自己的分。组合加成：三会 5、三合 4、五合/六合 3、半合 2、拱合 1。赢家总分 += 分差。
5. 揭示动画结束后自动进入摸牌，不需要点「继续」。随后换月令并翻出公共牌池：4 张天干在上、4 张地支在下。牌面只对当前选牌者可见；选走后位置留空，对手只知道「天干/地支已取」，不知道具体牌。赢家先选 0–2 张，也可以不摸；赢家选完，输家再决定摸或不摸（最多 1 张）。双空过则双方各可选 0–1 张。摸牌限时 60 秒；可花 5 总分刷新一次牌池，总分不足 5 不能刷新；刷新只影响自己的牌池视图：赢家刷新后，输家仍拿未刷新的原池；输家刷新只替换自己视图里剩余的牌；无人可挑时自动进入下一回合。手牌打空者不参与牌池，直接补满 8 张（4 天干 + 4 地支）。
6. 第 12 回合结算后终局，比较总分；不再换月/摸牌。
7. 每回合分出胜负时只播放胜方得分反馈：胜方牌面亮起、总分旁显示 +分差、总分金色脉冲；败方不播放受击/掉血/扣分动画。动画结束后自动进入摸牌，不需要点「继续」。

快捷操作：选牌后 `Enter` 出牌（需先转化/合成），`P` 空过，`Esc` 清空选择。
右上角可切换出牌 60/30/15 秒或不限时（仅本机试玩）；摸牌阶段固定 **60 秒**。倒计时不显示秒数，而是显示在中央「出牌 / 摸牌」阶段环的外圈；打开「规则」时倒计时自动暂停。

## 颜色提示

- 手牌按天干、地支分上下两行摆放，行首显示张数。
- 牌面主色 = 牌自身五行：金白、木绿、水黑、火红、土黄。
- 牌角的小圆点 = 与手中其他牌可合化出的五行副色，可同时有多个，
  同色合并；不覆盖主色。
- 所有组合都只在产出五行当月旺时成立：三会、三合、六合、半合、拱合、天干五合统一要求月令五行与产出五行相同。
- 副色只是提示，判定与计分始终以规则为准，且只对自己可见。

## 项目结构

```text
game.md                 规则与策划（唯一来源，不含技术）
index.html              页面骨架
styles.css              主题、卡牌、布局、动画
server.mjs              零依赖静态服务器（默认 5180）
src/rules.js            牌表、五行生克、月令、旺相休囚死、RNG
src/combos.js           组合定义、校验、枚举、计分、颜色副色
src/engine.js           对局状态机（纯逻辑，可在 Node 直接运行）
src/ai.js               AI 出牌/牌池选牌/补牌
src/main.js             渲染、计时、交互、阶段流转
tests/rules.test.mjs    规则与计分单测（node:test）
tests/selfplay.mjs      AI 自对弈与指标
tests/e2e.mjs           无头 Chrome 冒烟测试与截图
技术实施计划.md          技术实现：架构、算法、联机、测试与风险（不含规则裁定）
```

## 已知限制

- 单机版没有服务端权威，前端状态可被修改；联机版需要服务器校验与信息裁剪。
- 刷新页面会重开本局（联机版会做断线重连）。
- 对手手牌张数以「推算」标注直接显示，便于试玩；严格按策划书「不直接显示」
  可隐藏该数字，让玩家自行记录公开动作。
- 弃牌只指「弃1摸1」暗池换牌。
- AI 为启发式决策，空过率约 1.4%，不是 ISMCTS/强化学习。
- 12 回合目前固定；若要短局（6 回合）可改 `DEFAULT_CONFIG.maxRounds`。
- 规则与技术已拆分：改规则只动 `game.md`，再同步 `src/rules.js` / `src/combos.js` / 测试；技术细节只在 `技术实施计划.md` 维护。
- 三会/三合/六合/半合/拱合/天干五合都只在产出五行当月旺时成局。
- 手牌按五行槽整理：天干、地支各 5 个槽（木火土金水），每个槽有五行底色；槽位紧凑，两行拉开；同槽多张按蜘蛛纸牌式纵向压叠，只露顶部牌名/分数，点选后抬到最上层。
- 单牌先点「转化」、多牌先点「合成」，生成五行牌预览后再点「出牌」。
- 对手出牌时对战槽显示牌背，空过显示「空过」；你出牌后才揭示对手牌面。
- 牌面数字是单牌分（旺相修正已翻倍）；月令支牌固定显示 10，并带「令+5」标记。
- 牌池牌面只对当前选牌者可见；对手只看到空位类型（天干/地支）。赢家可选 0–2 张（也可以不摸），输家可选 0–1 张；双空过时你先挑、电脑后挑；打空者不参与牌池，直接补满 8 张。
- 每回合一次「弃1摸1」：不消耗出牌权；弃 1 张后从 4 天干 + 4 地支暗池盲选 1 张，其余 7 张丢弃；取消则原牌退回。
- 摸牌池刷新：花 5 总分；每个玩家独立视图。赢家刷新只替换自己的整池，输家仍拿原池；输家刷新只替换自己视图里剩余的牌，不补回被拿走的位置。
- 「再来一局」和「重开」都会重新进入定月转盘，重新拨两次月盘并重新随机取月/顺逆，不会复用上一局月令。
- 摸牌 60 秒倒计时：赢家超时自动拿前 2 张，输家/可选方超时自动不摸。
- 桌面为玩家左、对手右；月令轮盘指针随月令转动；地支牌恢复地支大字，天干牌保持大字。
- 中央上方显示「出牌 / 摸牌」阶段环，外圈金色周长随时间收缩，不显示秒数；揭示动画结束后自动进入摸牌。
- 桌面端锁一屏；侧栏只保留月令轮盘，不再显示对局记录；移动端可纵向滚动查看轮盘。
- 暂无声效；动效使用 CSS + Web Animations API，尊重 `prefers-reduced-motion`。
- 转化/合成有牌面收束与元素光效；出牌后先亮己方牌，再聚焦并翻面对手暗牌；翻面完成前隐藏总分和结算摘要，避免剧透。
